# The browsable site

Generated by [`tools/build_docs.py`](../tools/build_docs.py) — run `make docs`
after a data refresh or a document edit. GitHub Pages serves this directory at
<https://tecunningham.github.io/ai-discovery-data/>, and it is the canonical
place to *browse* the collection: each series page renders its problem
folder's full README with the interactive chart embedded where the document
embeds its primary PNG, the site index is the root README, and CUMULATIVE.md
and ADDITIONAL-CANDIDATES.md have pages of their own.

The repository stays the archival record. Every chart is a Vega-Lite spec
with the folder's CSV rows inlined, supplementary PNGs are served from the
repository's raw URLs rather than copied here, and the committed PNGs remain
the static, byte-reproducible versions of every figure.

Do not edit the HTML by hand — edit the READMEs or the spec registry in
`tools/build_docs.py` and rebuild. The build fails loudly if a problem folder
has no registered spec, so a new series cannot silently ship without its
page, and `tools/check.py` fails when any page no longer matches what the
builder renders today.
