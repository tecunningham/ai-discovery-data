ai-discovery-data — interactive charts

Interactive companions to the static charts in the repository. Hover any mark for the underlying record; on several charts a click opens the original reference.

  • CIFAR-10 speedrun — seconds to 94% test accuracy on CIFAR-10 on a single A100
  • CVRPLIB X-instance record frontier — better best-known objectives and later optimality proofs recorded for a fixed cohort of 100 CVRP X instances
  • ECDSA.fail secp256k1 point-addition circuit — best validated score (average executed Toffoli count × peak qubit width) for a reversible secp256k1 point-addition circuit; lower is better
  • Hutter Prize compression: enwik9 — total size in bytes of decompressor plus archive for a fixed 1 GB text corpus, under a CPU-time and memory cap
  • Gurobi mixed-integer programming speed — cumulative vendor-reported MILP speedup across releases, every version rerun on one machine
  • MIPLIB 2017 solution frontier — better feasible incumbents, first feasible solutions and optimality updates announced in MIPLIB 2017 solufile releases
  • modded-nanogpt training speedrun — minutes of training to a fixed target validation loss, per accepted record
  • Stockfish development builds on fixed hardware — Elo relative to Stockfish 15, from 20,000 games per build on one fixed machine and time control
  • curl vulnerability disclosures — vulnerabilities disclosed per quarter, split by finder credit
  • Firefox vulnerability disclosures — distinct CVEs per quarter, split by whether the reporter credit names an AI method, an AI-security employer, a fuzzer, or none of these; advisory–CVE mentions retained as a sensitivity count
  • All software: vulnerabilities known exploited — CVEs added per quarter to CISA's Known Exploited Vulnerabilities catalogue
  • Microsoft security-update CVEs — CVEs issued by Microsoft's own CNA per month, dated by first publication in the Security Update Guide, split by whether an acknowledgment credit names an AI method, an AI-security employer, a fuzzer, or none of these
  • All software: vulnerabilities disclosed — CVEs published per quarter in the US National Vulnerability Database
  • OpenSSL vulnerability disclosures — vulnerabilities disclosed per quarter, split by finder provenance
  • OSS-Fuzz vulnerability discoveries — vulnerability records published per quarter by an automated fuzzing programme
  • Open-source CVEs represented in OSV — distinct CVE IDs linked to at least one active affected-package record in OSV, per quarter by earliest OSV publication date
  • Integer factorization records — cryptanalysis; decimal digits in the largest hard semiprime factored, as a running maximum
  • Inventory of the AlphaEvolve problem set — per problem, whether it has a live numeric record and how many dated prior works the paper cites
  • Finite construction records around AlphaEvolve — cumulative record steps in five groups of finite construction and packing problems
  • ANTEDB analytic-number-theory exponents — cumulative slice-level record changes across 58 exponent slices in the three families $\mu$, $A$ and $\beta$
  • Erdős problems catalogue — problems catalogued, statuses marked solved, and statements formalized in Lean, at monthly site snapshots; plus an imputed solution year per solved problem
  • Hilbert's problems — dated resolutions per year across 28 scored rows
  • Landau's problems — dated resolutions per year across 4 scored rows
  • Millennium Prize Problems — dated resolutions per year across 7 scored rows
  • Smale's problems — dated resolutions per year across 19 scored rows
  • Sphere-packing lower-bound ladder — cumulative improvements to the asymptotic lower bound on sphere-packing density in high dimension
  • Sums-and-differences and autoconvolution constants — best known lower bounds on two additive-combinatorics constants, $C_{6.44}$ and $C_{6.3}$ in the AlphaEvolve numbering
  • Thurston's 24 questions — dated resolutions per year across 24 scored rows
  • The Open Problems Project — dated resolutions per year across 78 scored rows
  • Matrix-multiplication exponent ω — best proved upper bound on the asymptotic exponent ω of n×n matrix multiplication; lower is better
  • arXiv submissions — research output; preprints submitted to arXiv per month
  • DOI records deposited with Crossref — formal publishing volume; DOI records deposited with Crossref per year, by created date
  • Git pushes to GitHub — code output; git pushes to GitHub per quarter, summed over economies
