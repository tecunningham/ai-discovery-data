# Interactive chart pages

Generated by [`tools/build_docs.py`](../tools/build_docs.py) — run `make docs`
after a data refresh. One self-contained HTML page per problem folder, with
the folder's CSV rows and a Vega-Lite spec inlined; GitHub Pages serves this
directory at <https://tecunningham.github.io/ai-discovery-data/>.

These pages are companions to, not replacements for, the committed PNGs in
each problem folder: the PNG is the static record embedded in the READMEs and
the root index; the page here adds hover detail per record and, where the data
carries a source URL, click-through to the original reference.

Do not edit the HTML by hand — edit the spec registry in `tools/build_docs.py`
and rebuild. The build fails loudly if a problem folder has no registered
spec, so a new series cannot silently ship without its interactive page.
